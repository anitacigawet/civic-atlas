# Civic Atlas

Civic Atlas is a maintained directory of civic data sources — datasets,
portals, APIs, agent/MCP access layers, communities, and working projects —
organized by country and subject. The public community lives at
[r/CivicAtlas](https://www.reddit.com/r/CivicAtlas/).

This repository holds the source of the
[Yellow Book](yellow-book.md) (the subreddit's start-here megathread) and, as
it grows, the machine-readable registry behind it.

## Maintained with AI assistance

This directory is maintained with AI assistance, and every entry is checked
against its official source before it goes in. If anything here is wrong or
out of date:

- open a pull request,
- open an issue, or
- comment on [r/CivicAtlas](https://www.reddit.com/r/CivicAtlas/).

No moderator status is needed to propose a correction.
